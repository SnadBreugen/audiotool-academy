# Audiotool Academy — Interactive Lesson Prototype

**Episode: The Mixer — Inside a Channel Strip**

An interactive HTML learning experience for Audiotool. Single self-contained file — all images, voiceovers, and the music loop are embedded.

## Run it

Open `index.html` in a browser, or visit the GitHub Pages URL of this repo. Desktop recommended.

## Modes

- **Explore Mode** — click each module of the highlighted channel strip at your own pace
- **Cinema Mode** — guided tour, plays through automatically with narration

## Features

- Hotspot navigation on a real mixer screenshot, with narration-synced highlights
- Voiceover-driven timing (ElevenLabs, "Revenant")
- Background loop (130 BPM) running through a live Web Audio effect chain — each module plays a scripted sound demo (EQ cuts, compression, sidechain pump, sends, fader/pan)
- Practice template link at the end of the lesson

## Notes

- The five module detail images are loaded from help.audiotool.com — everything else works offline
- Built as a test run for a planned lesson series (Stagebox → Mixer)
